# Unit-6-Weekly-Prompt
My weekly prompt for unit 6
The question I will be answering is this, "In Chapter 13, the rocket ship fires bullets to destroy the alien spaceships. This is accomplished by using the sprite utility groupcollide(). Search the pygame documentation or other resources on the web and discuss this method does." The groupcollide() method works by tracking two group of sprites to determine if at any point time they collide any member of either group collides with any member of the other group. This process is done by look at the rectangles of all of sprites in each group and see if they at anypoint intersect, and if they do collide, they will then be stored in a dictionary created by the method pairing which sprites that collide with each other. To be more specific the dictionary returns all sprites present in its first group and then, each sprite from group 1 will be pair with a list of all the sprites from group 2 that it collided with. The other function that this method possess is the ability to remove sprites from either or both groups when they collide through its, "dokill1" or "dokill2" argument. The names can basically be thought of as the method asking do I kill the sprite from group 1 and/or do I do the same for group2.
